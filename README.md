# Tharun Mani - Cinematic Portfolio 🎬✨

A high-end cinematic professional portfolio website built for **Tharun Mani** (Cinematic Photographer & Videographer) using modern web technologies.

## 🚀 Live Demo
Check out the live website here: [Tharun Mani Portfolio](https://tharunmani-portfolio.vercel.app/)

## 🛠️ Tech Stack
- **React (Vite)** - Fast and modern frontend framework
- **JavaScript (ES6+)** - Core logic and interactivity
- **CSS3** - Custom styling with cinematic dark themes and responsive design
- **GSAP** - Smooth scroll and interactive animations

## 📁 Project Structure
```text
TharunPortfolio/
├── public/         # Static assets (favicons, icons)
├── src/
│   ├── assets/     # Images and media files
│   ├── components/ # Modular components (Navbar, Hero, About, Projects, Services, Contact)
│   ├── App.jsx     # Main React component
│   ├── App.css     # Global styles/animations
│   ├── index.css   # Base styles and font configurations
│   └── main.jsx    # Entry point
├── package.json    # Dependencies and scripts
└── vite.config.js  # Vite configuration
```

## 💡 Features
- **Cinematic Dark Mode:** Premium dark aesthetics tailored specifically for professional videography and photography.
- **Fully Responsive:** Optimized layout for mobile, tablet, and desktop screens.
- **Interactive Sections:** Clean navigation across Hero, About, Projects, Services, and Contact.
- **Fast Performance:** Powered by Vite for lightning-fast load times.

## ⚙️ Local Development
If you want to run this project locally, follow these simple steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/karthees-m/tharun-mani-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd tharun-mani-portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
